What’s changed

2026-06-02• changed

Rebranded to "Devin Desktop"

Cognition rebranded the Windsurf IDE as “Devin Desktop,” unifying it with the cloud agent Devin under one product and opening it to third-party agents via the open Agent Client Protocol.

source →
2026-03-19↓ reduced

Flat credits replaced with daily/weekly quotas; Pro price up

Cognition replaced flat monthly credit-pool billing with a token-based system giving daily + weekly usage allowances, raised Pro from $15→$20/mo and Teams from $30→$40/seat/mo (both reportedly grandfathered for existing subscribers), and launched a new $200/mo Max tier.
