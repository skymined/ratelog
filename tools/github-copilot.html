plans

Every tier

Free tier: Copilot Free — 2,000 code completions and 50 chat requests per month, limited agent mode, restricted model set (Claude Haiku 4.5, GPT-5 mini). Resets monthly.

Copilot Pro
$10/mo
Unlimited code completions. $15 in total monthly AI Credits (1,000 base + 500 bonus) for chat, agent mode, CLI, and code review — token-metered, no rollover. Extra usage beyond that is $0.01/credit.
Individual devs stepping up from Free
Copilot Pro+
$39/mo
$70 in total monthly AI Credits (3,900 base + 3,100 bonus) — about 4.7× Pro’s allowance. Broader model access, including Claude Opus.
Power users with heavy chat/agent use
Copilot Max
$100/mo
$200 in total monthly AI Credits (10,000 base + 10,000 bonus) — about 2.9× Pro+’s allowance. Priority access to new models.
Heavy, sustained agentic workflows
Copilot Business
$19/mo
1,900 AI Credits per user/month, pooled at the org level so unused credits can be used by teammates. No rollover.
Small/medium organizations
Copilot Enterprise
$39/mo
3,900 AI Credits per user/month, pooled at the enterprise level, same reset rules as Business.
Large enterprises needing deep GitHub.com integration

2026-06-01• changed

Flat premium-request quotas replaced with AI Credits

GitHub replaced its flat monthly Premium Request quotas (e.g. 300/month for Pro) with a token-consumption-based "AI Credits" system (1 credit = $0.01) across all plans, and introduced a new top individual tier, Copilot Max, at $100/month. Total credit allowances ended up higher than sticker price once bonus credits are included, but billing is now metered rather than a flat predictable count.
