Every tier

Free tier: Free Tier (AWS Builder ID or IAM) — 50 agentic requests/month (chat + agentic coding, IDE+CLI combined), 1,000 lines/month for Java code transformation, unlimited inline completions. New signups blocked since May 15, 2026; existing accounts keep working.

Pro Tier
$19/mo
10,000 inference calls/month (~1,000 requests) per user, 4,000 lines/month for Java transformation (overage $0.003/line), separate 1M lines/month .NET transformation quota. Agentic-request overage isn't purchasable — you wait for the next month.
